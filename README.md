## 🚀 Featured Projects

### 🩺 [Diabetes Risk Prediction](https://github.com/BhargaviAnupati/CDC-Diabetes-Health-Indicators-Analysis)
Predicting diabetes/prediabetes risk from 253K+ CDC health survey records. Compared Logistic
Regression, Random Forest, and XGBoost using a matched-recall evaluation methodology, and
interpreted the final model with SHAP.
**ROC-AUC: 0.815** &nbsp;|&nbsp; `Python` `scikit-learn` `XGBoost` `SHAP` `Streamlit`

### 📈 [Retail Demand Forecasting](https://github.com/BhargaviAnupati/Rossmann-Store-Sales-Forecasting)
Forecasting daily sales across 1,115 retail stores using 1M+ panel-data records. Built
time-aware features and a chronological validation split, then used a SHAP-based counterfactual
analysis to isolate the true impact of promotions on sales.
**20.8% estimated sales lift from promotions** &nbsp;|&nbsp; `Python` `pandas` `XGBoost` `SHAP` `Time Series`
